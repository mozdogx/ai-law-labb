AI LAW LAB

Purpose:
Build practical systems for researching, monitoring
and analysing AI regulation.

Current Phase:
Phase 1 — Build the AI Stack

Core principles:

1. Primary sources first
2. Every legal proposition must be traceable
3. AI output is not treated as legal authority
4. Human verification is recorded
5. Jurisdictions are kept separate
6. Regulatory changes are versioned
7. Automation assists legal judgement rather than replacing it
